## 🚨 PROBLEMA PRINCIPAL

**Error:** `net::ERR_NAME_NOT_RESOLVED`

```
Lo que significa:
  • Supabase está pausado, O
  • La conexión de red no alcanza Supabase, O
  • El dominio pnmzzgsgmqgzdwsodfla.supabase.co no responde
```

## ✅ SOLUCIÓN (Elige una)

### Opción 1: Reactiva Supabase (Más fácil)
```
1. Abre: https://app.supabase.com
2. Busca: pnmzzgsgmqgzdwsodfla
3. Settings → General
4. Haz click en "Unpause" si está pausado
5. Espera 30 segundos
6. npm run dev
7. F5 en navegador
8. ¡Listo!
```

### Opción 2: Crear todo nuevo (Alternativa)
```
1. Crea proyecto en: https://supabase.com
2. Copia la URL y ANON_KEY
3. Actualiza .env con los nuevos valores
4. Ejecuta scripts SQL en Supabase SQL Editor
5. npm run dev
```

## 📋 SCRIPTS SQL A EJECUTAR (en orden)

### Paso 1: Crear Tablas (OBLIGATORIO)
```
Archivo: scripts/complete-supabase-backend.sql
Ubicación: Supabase → SQL Editor → New Query
Resultado: 6 tablas creadas (users, products, clients, etc)

### Paso 2: Configurar Seguridad (OPCIONAL)

```

```

```
